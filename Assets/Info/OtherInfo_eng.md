## [Useful information]

* The mod is compatible with Environment Remaster (install after The Honor of a Mercenary)

### New console commands have been added to the game:
* givefuel () — fully refuels the player’s vehicle.

* givehp () — fully repairs the player’s vehicle.


## [Known issues]
* Roads and water are displayed incorrectly in some places.

## [Version history]

### Version 1.0

1. The ExMachina Demo storyline has been fully ported to Community Remaster.
2. Appropriate battle voiceovers have been added for the ExMachina Demo Main Hero.
3. Some errors in dialogues, cutscenes and quests have been fixed.
4. A «One Life» mode has been added, which can be enabled at the start of the game. In this mode, saving is disabled, meaning the playthrough must be restarted from the beginning if the player dies.
5. Changes have been made to vehicle textures.
6. Some changes and fixes have been made to interface textures.
7. New loading screens have been added.
8. Minor balance adjustments have been made.
9. One new quest has been optionally added.

### Version 1.1

1. The mod has been adapted for Community Remaster 1.14.
2. Some errors and bugs have been fixed.
3. Some texture edits have been moved to a separate mod.

### Version 1.2 [build 251226a]

1. Cutscenes and scripts have been fixed and improved.
2. Music has been added to cutscenes that previously had none.
3. The volume of some lines in cutscenes has been increased.
4. Dialogues have been fixed and slightly refined.
5. Quest markers and descriptions have been corrected.
6. NPC pathfinding maps have been fixed.
7. Incorrect positioning of some objects in the locations has been fixed.
8. Weather and lighting in the locations have been slightly improved.
9. Boxes with random weapons have been added to the locations.
10. Some textures have been fixed.
11. Balance adjustments have been made.
12. Credits have been added after the game ends (taken from Improved Storyline).
13. AmmoMiniMod Reborn has been integrated as an option.
14. Extra characters have been removed from the «New Quests» option.
15. The «One Life» mode has been removed.
16. Other minor changes and fixes.

### Version 1.3 [build 251227a]
1. Cutscenes and scripts have been fixed and improved.
2. Dialogues have been fixed and slightly refined.
3. Quest markers and descriptions have been corrected.
