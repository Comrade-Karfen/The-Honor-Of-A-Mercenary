### Useful Information
**New console commands have been added to the game:**

* givefuel () – fully refuels the player's vehicle.
* givehp () – fully repairs the player's vehicle.

### Version History

 **Version 1.0**
1. The ExMachina Demo storyline has been fully ported to Community Remaster.
2. A more suitable combat voice-over has been added for the ExMachina Demo main character.
3. Some errors in dialogs, cutscenes, and quests have been fixed.
4. Added a “One Life” mode that can be enabled at the start of the game. In this mode, saving is disabled, so if you die, you will have to start the playthrough over.
5. Vehicle textures have been changed.
6. Some changes and fixes have been made to interface textures.
7. New loading screens have been added.
8. Minor balance adjustments have been made.
9. New quests have been added as an option.
